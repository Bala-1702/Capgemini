We can link bootstrap using CDN(Content Delivery Network)
A CDN (Content Delivery Network) is a system of geographically distributed servers that work together to deliver digital content—like web pages, images, videos, and scripts—more quickly and efficiently to users based on their location.

Here's how it works:
When you access a website, instead of fetching all the content from a single central server (which might be far away), a CDN delivers it from a server that's physically closer to you.
This is done through caching, where static content is stored on multiple edge servers around the world.

Node JS :
	Node.js is a powerful, open-source JavaScript runtime environment that allows you to run JavaScript code outside of a web browser, typically on the server side.

Key Features of Node.js:
	Built on Chrome's V8 Engine: It uses the same engine that powers Google Chrome, making it fast and efficient.
	Asynchronous and Non-blocking: Node.js handles multiple operations at once without waiting for one to finish before starting another—great for real-time applications.
	Single-threaded but Scalable: Uses an event-driven model to handle many connections efficiently.
	Cross-platform: Works on Windows, macOS, and Linux.

Why Node JS?
	JavaScript was originally designed to run only in web browsers, allowing developers to create interactive websites. However, with the introduction of Node.js, JavaScript can now run outside the browser, on the server side. Node.js provides a runtime environment that includes everything needed to execute JavaScript code on a server, such as file system access, networking capabilities, and more.
